## Phase 2 — PR CI remediation

### Root causes diagnosed

1. Used `get_pull_request_status` to check CI — that API measures commit-status objects, not
   GitHub Actions checks. GitHub Actions uses the Checks API. Status API returned
   `total_count: 0` / pending, masking real failures. Wrong API, wrong conclusion.

2. `commit.gpgsign=true` → SSH-signed commits. `Signed-off-by:` (DCO) is a separate commit
   message trailer — not added by signing. No `trailer.sign` config set → DCO never appeared.

3. `git rebase -i` opened vim in non-TTY → hung. Fix: `GIT_SEQUENCE_EDITOR=true`.

4. Workspace file tools (`read_file`/`write_file`) operate within the workspace root at
   `worktrees/single-analyzer`. The PR worktree is at
   `/home/dean/code/llm-d/worktrees/pr-single-analyzer` — outside the workspace. All edits
   to that worktree must go through `execute_command`.
