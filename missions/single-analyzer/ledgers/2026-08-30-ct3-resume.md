## Corrections/lessons worth remembering

- **Never let a delegated agent edit `CONVENTIONS.md` on this mission's authority.** Only
  `policy-writer` owns that file. A ledger-capture (or any) agent that surfaces a
  genuinely-global finding should write it to `suggestion-box/` instead, in the existing
  `<date>-<seq>-<mission>.md` format (Source / Candidate rule / Why / Where it might land) —
  see `suggestion-box/2026-08-28-0400-policy-writer.md` for the established shape. Don't
  grant "edit CONVENTIONS.md directly if you judge it global" as an option in a ledger-
  capture agent's instructions again.
- **Staying on-mission during resume matters even when answering a direct question.**
  Answering a user's question about a sibling mission's ledger is fine; continuing to work
  that sibling mission, or losing track of the fact that the *next* action should be this
  mission's own next step, is not. `/resume-mission`'s whole point is continuing the *same*
  mission's own prior session, not general mission-tracking-system exploration.
